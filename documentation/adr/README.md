# Architecture Decision Records

ADR фиксируют решения, которые влияют на несколько компонентов или меняют trust boundary. Принятое решение не редактируется задним числом: изменение оформляется новым ADR, который supersedes старый.

## Статусы

`Proposed`, `Accepted`, `Deprecated`, `Superseded`.

## Шаблон

```text
# ADR NNNN — Название
Status / Date / Owners
Context
Decision
Consequences
Alternatives
Verification
```

Каждый ADR обязан описывать способ автоматической либо операционной проверки решения.
