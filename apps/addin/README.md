# Excel Add-in

Office Web Add-in host application. Contains only host entry points and presentation composition.

- `src/taskpane` — React sidebar.
- `src/commands` — Ribbon command entry points.
- `src/custom-functions` — isolated Excel Custom Functions runtime.
- `src/app` — dependency composition.
- `manifest` — development and production Office manifests.
- `public/assets` — icons and static assets.
